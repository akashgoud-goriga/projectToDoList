# 📝 To-Do List App

A simple To-Do List application built using HTML, CSS, and JavaScript.

## ✨ Features

- Add new tasks.
- Display added tasks at the bottom of the task list.
- Mark tasks as completed.
- Completed tasks are shown with a strikethrough.
- Delete completed tasks from the list.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Use

1. Open the To-Do List application.
2. Enter a task.
3. Click the Add button to add the task.
4. Your task will appear in the task list.
5. Click the Completed button to mark a task as completed.
6. The completed task will be struck through and deleted.
